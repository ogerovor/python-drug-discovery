# Python Drug Discovery Tools
A collection of command line calculators for drug discovery, built while learning python for my Phd in phytomedicine drug discovery and development.
## Tools
| # |Script|What it does|
|---|------|------------|
| 1 |drug_dose_calculator.py| Computes drug dose from patient weight|
| 2 |lipinskis rule of 5 checker.py| checks lipinskis rule of 5|
| 3 | percentage inhibitor calculator.py| Calculates perventage inhibition from assay data|
| 4 | Dilution Series generator.py| generates serial dilution concentrations|
| 5 | Body Mass index+Drug clearance calculator.py| estimates drug clearance by body weight|
| 6 | LogP estimation.py| Estimates LogP from atomic contributions|
## How to Run
```bash
python drug_dose_calculator.py
